Tab Organizer privacy policy

Last updated: 21 September 2026 · Extension version 0.3.1

Tab Organizer is a Chrome extension that helps users organize open browser tabs into topic-based groups. It has no Tab Organizer account, advertising, subscription, or sale of data.

Operator and contact

Public pseudonym: beastyrabbit

For support and privacy questions, use the Tab Organizer issue tracker. Do not post passwords, client keys, complete page contents, or other confidential information there.

Information the extension handles

  • Tabs and tab groups: tab titles, URLs, domains, window and tab identifiers, group membership, group names, group colors, and references to website icons. These are needed to display tabs and propose organization.
  • Selected page information: during a user-requested organization, the extension may read page metadata or a text excerpt from selected HTTP or HTTPS pages when a title and URL are not enough to classify a tab.
  • User settings: organization instructions, protected groups, memories, model settings, proxy settings, and saved tab sets.
  • Local results: proposals, summaries, caches, and recent run history.
  • Proxy credentials: the proxy address and an optional proxy client key if the user enters them in Settings.

Tab titles, URLs, instructions, and page excerpts can contain personal or confidential information. The extension does not automatically redact that information.

How information is used

The extension uses this information to display tabs, create grouping proposals, show summaries, apply changes the user confirms, verify the result, and provide its local interface. It does not use tab information for advertising, profiling, credit decisions, or sale.

User-configured AI proxy

For AI features, Tab Organizer sends the information needed for the requested operation to the EasyCLIProxyAPI address entered by the user. This can include tab titles, URLs, group data, user instructions, and selected page metadata or text. The proxy can forward the request to the AI provider configured there.

beastyrabbit does not operate a Tab Organizer server that receives tab data. The selected proxy and AI provider process requests under their own terms and privacy policies. Their retention, deletion, security, and processing locations are their responsibility.

Connection checks and model discovery can contact the configured proxy outside an organization run. These checks do not need to include tab contents.

Tab Organizer does not read Codex CLI auth.json files and does not include an OpenAI API key. The user configures and authenticates the separate proxy.

Website icons and external requests

To help users recognize tabs, the extension loads website icons from the website or its icon host. If an icon is unavailable, it may request an icon from Google's favicon service using the tab's domain name. The requested domain, IP address, and ordinary technical connection data may be sent to Google. Google's privacy policy applies to that service. This request can happen while tabs are displayed, without starting an AI operation.

Storage on the device

The extension stores settings and local records in chrome.storage.local in the user's Chrome profile. It does not use Chrome Sync for these records. Stored information can include proxy settings, the optional client key, rules, memories, protected groups, saved tab sets, summaries, and recent runs.

The user can clear recent runs in Settings, clear the extension's Chrome storage, or uninstall the extension. Removing local data does not delete information already sent to the configured proxy, AI provider, or icon service; those services control their own retention.

Security

HTTPS protects communication with an HTTPS proxy. If the user configures an HTTP proxy, the connection does not have HTTPS transport protection. The optional proxy client key is stored locally and sent to the configured proxy as an authorization header. Chrome local storage is not a separate password vault.

Legal basis and rights

This is a private, non-commercial hobby project. Processing takes place to provide functions the user requests. Where data protection law applies, the user may have rights of access, correction, deletion, restriction, objection, and portability depending on the circumstances. Requests about data held by the configured proxy or AI provider must be directed to those services.

Privacy questions can be raised through the public issue tracker. A complaint may also be submitted to a competent data protection authority.

Changes to this policy

This policy may change when the extension or its processing changes. The date above identifies the current version.
