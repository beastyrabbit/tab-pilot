Zusammenfassung, exakt wie im 0.3.1-Manifest

Organize Chrome tabs with a user-configured local AI proxy, protected groups, and a reviewable proposal.

Beschreibung

Tab Organizer groups open Chrome tabs by topic and task. Review the proposed changes before applying them, keep uncertain tabs ungrouped, and mark important groups as protected favorites.

Features
• Preview proposed groups before applying changes.
• Preserve and prefer protected favorite groups.
• Use existing groups or create focused new groups.
• Choose soft grouping for cautious suggestions or hard grouping for complete coverage.
• Inspect recent runs and the verified result after Apply.
• Detect exact duplicate URLs and optionally close older copies.
• Select models and supported thinking options through your configured proxy.

AI connection
This extension requires an EasyCLIProxyAPI instance that you run and configure separately. It does not include a hosted AI service or an OpenAI API key. EasyCLIProxyAPI can connect through Codex OAuth using a compatible ChatGPT subscription, subject to the provider's availability and terms.

Install EasyCLIProxyAPI, connect your supported provider there, and enter its API base URL in Settings. The default address is http://127.0.0.1:8317/v1. If your proxy requires a client key, enter that key in Settings. This is the proxy's key, not a requirement to purchase an OpenAI API key.

Privacy
AI operations send tab titles, URLs, group information, your instructions, and selected page metadata or text excerpts to the proxy you configure. The proxy forwards requests to its configured AI provider. Settings and run history are stored locally in Chrome. Tab Organizer does not operate a server that receives your tab information. Website icons may load from external sites; a Google favicon fallback may receive the tab's domain. See the privacy policy for details.

4. Datenschutzformular

Alleiniger Zweck · Single purpose description

Help users organize their open Chrome tabs into topic-based tab groups. The extension shows current tabs and generates grouping proposals through a user-configured AI proxy. Users review proposals before applying them and can protect favorite groups. Local settings, saved tab sets, duplicate handling, and run history support this tab-organization workflow.

Begründung für tabs

The tabs permission is used to read open tab titles, URLs, window IDs, and group IDs, display the current tab list, and build tab-organization proposals. It also supports user-requested tab actions, including moving tabs and optional duplicate closure. The extension does not read the user's full browser history through the history API.

Begründung für tabGroups

The tabGroups permission is used to read existing group names and colors and to create, update, collapse, and reorder tab groups as part of user-requested organization. Existing protected favorite groups are retained. AI proposals are presented for review before their grouping changes are applied.

Begründung für activeTab

The activeTab permission supports access to the current page following a user interaction with the extension, for page-context inspection used in tab organization. Inspection reads page metadata or text to help classify tabs; it is not used to monitor typing or interactions.

Vor Abgabe prüfen, ob activeTab neben den breiten Hostberechtigungen tatsächlich benötigt wird. Wenn die Berechtigung ungenutzt ist, im Paket entfernen und neu bauen, statt eine nicht vorhandene Funktion zu behaupten. Nicht während des bloßen Ausfüllens stillschweigend Code ändern.

Begründung für sidePanel

The sidePanel permission provides the Tab Organizer interface alongside the user's browsing session. The panel displays tabs, organization settings, protected groups, AI proposals, and recent run results so users can review and apply changes without navigating away from their pages.

Begründung für scripting

The scripting permission runs packaged extraction code on selected HTTP or HTTPS tabs during user-requested organization to read page metadata or page text when titles and URLs are insufficient. This context helps classify tabs. Extracted page content is treated as data. The extension does not download or execute remote scripts.

Begründung für favicon

The favicon permission is used to display website icons through Chrome's extension favicon endpoint in the proposal interface. Icons help users recognize the tabs they are reviewing before applying organization changes.

Begründung für storage

The storage permission stores extension settings, the user-configured proxy address and optional proxy client key, protected-group markers, memories, saved tab sets, summary cache, and recent run history in chrome.storage.local on the user's device. The extension does not use Chrome sync storage for these records.

Begründung für Hostberechtigung

HTTP and HTTPS host access is used to connect to the user's chosen EasyCLIProxyAPI endpoint, which can be a localhost, local-network, or HTTPS address, and to extract metadata or text from selected web pages for user-requested tab organization. The proxy host and the tabs to organize are not known at installation time. Tab icons may also load from external sites or Google's favicon service. These requests support the tab-organization interface; no remote executable code is loaded.

Tab Organizer 0.3.1 review instructions

Purpose
The extension organizes open Chrome tabs into groups. Users review AI proposals before applying them and can protect favorite groups.

Setup
1. Install the submitted Manifest V3 extension and open its side panel from the toolbar.
2. Local UI features can be inspected without an AI connection, including the tab list, settings, group controls, and run-history interface. Generating an AI proposal requires the proxy setup below.
3. Install and run EasyCLIProxyAPI separately: https://github.com/router-for-me/EasyCLIProxyAPI
4. Authenticate a supported provider in that proxy. For Codex OAuth, use a reviewer-controlled account with the required provider access. The extension does not include developer credentials and does not read Codex CLI auth.json files.
5. In extension Settings, enter a proxy API base URL reachable from the machine running Chrome. The default is http://127.0.0.1:8317/v1. Here localhost refers to the reviewer's machine, not to a developer-hosted service.
6. If the proxy requires a client key, enter the reviewer's own proxy client key. This is separate from an OpenAI API key. Do not enter a proxy management key.
7. Check the connection and load models. Model discovery calls GET /models under the configured base URL. AI requests use POST /chat/completions. Choose an available model and options supported by that proxy.

Core test
1. Open several non-sensitive public pages covering two or three topics.
2. Create a tab group for one topic and mark it as a protected favorite using the star control.
3. Click Organize Tabs and wait for the proposal.
4. Expand the proposed groups and inspect assignments. Tabs with uncertain matches may remain ungrouped in soft mode.
5. Click Apply and confirm the proposed tab grouping is applied and the protected favorite is retained.
6. Open Settings and the recent-run history to inspect the recorded proposal and post-Apply result.
7. For a failure-path test, configure an unreachable proxy and confirm the connection error is shown. This does not test successful AI organization.

Data and code
The extension reads tab information and may extract page metadata or text for classification. It sends AI inputs to the configured proxy. Settings and run history are stored in chrome.storage.local. Website icons may load externally, including a Google favicon fallback. All executable extension code is bundled; remote AI responses are processed as data.

No shared username, password, API credential, or hosted reviewer endpoint is provided. Full AI review requires the reviewer's configured proxy and provider access. If this setup is insufficient for your review process, please request an alternative review arrangement from the publisher.
